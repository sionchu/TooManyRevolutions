## Scope

F05_FIX18 closes the smallest runtime seam after the static FIX17 authoring
contract. An already active coup Conflict may receive an explicit validated
`COUP_COORDINATION_RESPONSE` ActionRecord for one authored required node. The
implementation consumes that record during the existing validated-action
resolution phase and does not create responses from strategy, agenda, random
state, time, resources, organization, scores, or territorial observations.

The static `CoupCoordinationNodeDefinition` and `CoupCoordinationProfile` remain
ScenarioDefinition-owned. `requiredNodeIds` is still an unordered necessary
set. There is no majority, quorum, weight, score, timer, cooldown, countdown,
or third `uncommitted` alignment. A node is uncommitted precisely when its
Conflict/node entry is absent from the sparse runtime response map.

## Runtime contract

`WorldState.coupCoordinationResponses` is indexed as:

```text
ConflictId -> CoupCoordinationNodeId -> CoupCoordinationResponseState
```

Each accepted state stores only `conflictId`, `nodeId`, `alignment`,
`actionId`, `eventId`, and `respondedAtTick`. A response is accepted only when
the Conflict is active and coup-kind, exactly one authored profile matches the
participating Country/Faction pair, the node is in that profile's required set,
the node belongs to the profile Country, and the node has not already received
a decisive response. Invalid schema/payload, missing or resolved Conflict,
non-coup Conflict, missing/ambiguous profile, non-required/foreign node,
profile-reference inconsistency, and duplicate/reopen attempts are deterministic
no-ops. A final all-coup response is preflighted before writing response state,
so a missing, foreign, or current-at-resolution successor Government cannot
partially record the invalid final action.

Successful responses emit exactly one
`COUP_COORDINATION_NODE_RESPONDED` event. Its actor/target and payload preserve
the node, Conflict, alignment, and source ActionRecord ID. The response state
points back to both the ActionRecord and event. An incumbent response resolves
the Conflict through `applyConflictOutcome()` with status quo. When every
required node is explicitly coup, the same sink receives the authored,
same-Country successor Government and coup Faction winner. A partial set keeps
the Conflict active. The existing sink remains the only Government mutation
path and no LandHex state is changed by this slice.

## Persistence and replay

The snapshot contract advances once from V6 to strict
`SerializedSimulationSnapshotV7`. V7 requires the sparse response map and
rejects V6/older envelopes; it does not migrate or invent response state.
Nested map keys must match response identities. The decoder rejects empty or
malformed IDs, unsupported alignments, invalid ticks, duplicate decisive node
state, and malformed map shape.

Runtime closure verifies that every response has an accepted matching action,
exact v1 payload, authored profile/node references, and valid outcome
consistency. Persistence verifies that every response has exactly the matching
`COUP_COORDINATION_NODE_RESPONDED` event with stable actor/target/payload
provenance, and rejects orphan response events. Empty, partial, and resolved
response maps round-trip canonically; save/load continuation retains action,
event, cause, Government, Conflict, and response-state equality.

## Boundaries preserved

- No autonomous response producer was added.
- No response action is generated by T018 political crisis detection.
- Coup conflicts still have no automatic territorial front or LandHex writer.
- No T021 territorial rule, T022 consolidation rule, or T023 dissolution rule
  was changed.
- No Conflict, Government, Faction, or Country runtime schema was changed.
- FUND_MOVEMENT and its F05/FIX9/FIX13 lifecycle remain outside this slice.
- Gate 1F and V02 remain outside this task.

The explicit response seam is therefore a runtime vertical slice, not a pacing
or late-state repair claim. The existing late-state diagnostic remains the
historical mixed-gap result and is not reclassified by F05_FIX18.
