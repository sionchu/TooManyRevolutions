### Phase C — internal action coverage audit

Audit `FUND_MOVEMENT` first because it is the observed selected action in the F05_FIX9 late freeze. Audit `ORGANIZE` only as a fallback/comparator.

For each candidate evaluate all of the following gates:

1. **Natural reachability** — selected by the current deterministic chooser in the actual late population without threshold/order rewrites.
2. **Action object** — the action has or can minimally represent what the faction is doing, rather than relying on the action label alone.
3. **Target** — identify whether a target is required (for example a Region or other existing authoritative object). Do not infer a target silently from ideology labels or faction names.
4. **Commitment** — identify a bounded actor-owned commitment/lifecycle distinct from `Faction.currentStrategy`.
5. **Cost / opportunity cost** — identify an existing authoritative resource or explicit action opportunity that can be committed. Do not invent a generic political-power meter.
6. **Bounded consequence** — identify an existing downstream state dimension and consumer. No direct crisis/conflict/LandHex/continuity/terminal shortcut.
7. **Magnitude grounding** — no arbitrary `+0.1`, `-0.1`, percentage, duration, or conversion ratio may be invented. Existing authored constants may only be reused if their semantics actually match.
8. **Natural repeat limit** — the commitment/lifecycle must prevent free monthly stacking without an arbitrary cooldown.
9. **Causal visibility** — consequence must be able to change an existing Agenda, legal action set, crisis prerequisite, conflict strength input, or player response feasibility through existing consumers.
10. **Persistence/replay contract** — state required for the commitment must be explicitly persistent and deterministic if later implemented.
11. **No implementation-knowledge chooser** — do not simply suppress `FUND_MOVEMENT`/`ORGANIZE` because they currently lack consumers in order to force the chooser down to LOBBY.
12. **Reference grounding** — reuse the accepted F05_FIX5 resource-mobilization / advocacy grounding. If a new mechanism or numeric assumption is required, mark it as requiring a separate grounding step instead of inventing it.
