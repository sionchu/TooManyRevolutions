## 4. Gate 1F product standard

Use the actual GDD / AGENTS criteria, not a test-only definition of fun.

Gate 1F must establish that:

- policy/intervention choices create trade-offs;
- consequences are surprising but explainable;
- different choices can create different histories;
- the player has reasons to accelerate and reasons to pause;
- a representative headless run has a readable political arc;
- passing unit tests alone is not success.

The product targets roughly 5–10 simulated years for a short demo and 20–40 simulated years for a full run. F05 is headless, so it may assess structural simulated pacing, not claim final real-time UX pacing that requires later visual/time-control validation.

## 10. Political accommodation dominance audit

This is the highest-priority F05 carry-over question.

F04D reported approximately:

```text
WAIT                  treasury 123
MATERIAL_RELIEF        treasury 237
LEGALIZATION           treasury 527
COERCIVE_RESTRICTION   treasury 867
ACCOMMODATION          treasury 2447
```

The targeted review found that accommodation's high treasury is causally explained largely by delaying territorial loss and retaining the economic base. That is not itself a bug.

F05 must determine whether accommodation is nonetheless a broadly dominant strategy.

Do not judge dominance by final treasury alone.

Compare dimensions separately:

- action feasibility;
- treasury spend and later treasury trajectory;
- administrative load/opportunity cost;
- scarcity/unrest;
- grievance/organization;
- crisis eligibility and timing;
- conflict/territorial trajectory;
- government transition if any;
- consolidation eligibility/outcome;
- later decision options;
- repeatability / no-op protection.

Classify accommodation as one of:

```text
NOT_DOMINANT
CONDITIONALLY_STRONG
DOMINANCE_CANDIDATE
CLEARLY_DOMINANT
```

A strategy is not automatically dominant merely because it wins one validation state. It becomes a Gate 1F concern if it is at least as good in most meaningful dimensions across materially different states while imposing no important opportunity cost or political risk.

Do not tune accommodation in this task.

## 11. WAIT dominance audit

Measure whether doing nothing remains weakly or strongly dominant in any representative context.

Classify per context:

```text
WAIT_WORSE
TRADEOFF
WAIT_WEAKLY_DOMINANT
WAIT_STRONGLY_DOMINANT
```

The old F02/F04 WAIT results are historical evidence, not current truth after F04 repairs.

A Gate 1F PASS recommendation requires that active intervention is meaningfully valuable in at least important decision contexts and that the simulation does not systematically reward inactivity because player actions only add costs without political leverage.

## 12. Relative action-strength audit

Do not collapse action quality into one utility score.

For each response, record:

- cost;
- administrative load;
- implementation duration;
- direct authoritative effect;
- first downstream consumer;
- time until first observable consequence;
- duration/persistence of consequence;
- meaningful downside or opportunity cost;
- resulting political trajectory.

Flag obvious outliers where a tiny cost/duration produces disproportionately persistent leverage across contexts.

Do not rebalance yet.

## 13. Pacing / readable-arc metrics

For each representative branch, record enough data to judge a headless political arc.

At minimum:

- time to first meaningful pressure change;
- time to first player-relevant decision opportunity;
- time to first major crisis if any;
- time to first territorial change if any;
- crisis/conflict/recovery transitions;
- important institutional changes;
- consolidation eligibility transitions;
- longest interval with no meaningful political change;
- number/timing of major decision or event clusters in the chosen horizon.

Do not invent a universal 'fun score'.

Use these measurements to judge whether there are plausible:

```text
accelerate windows
→ emerging signal
→ pause / understand
→ intervene
→ observe consequence
```

cycles.

A long quiet interval is not automatically bad if there is changing material/political state the player could observe; however multi-year periods with no meaningful state, pressure, decision, or event movement are a strong warning.

## 14. Explainability / causal trace

For major branch differences, provide a compact causal explanation from actual state/events.

Examples of acceptable form:

```text
accommodation
→ grievance falls
→ rebellion prerequisite delayed
→ territory retained longer
→ treasury remains positive longer
```

or:

```text
legalization
→ politicalCompetition becomes plural
→ legal BARGAIN path opens
→ faction trajectory changes
→ crisis timing changes
```

Do not generate fake post-hoc narrative causes.

If an important outcome cannot be explained from recorded/current authoritative evidence, flag `CAUSAL_READABILITY_GAP`.

## 15. History diversity

F05 should establish choice-driven diversity, not RNG-driven diversity.

Measure branch trajectory signatures using existing event/state/territory/government/outcome evidence.

Do not require every strategy to end differently.

But a representative context should not collapse all plausible responses back into effectively the same political history.

If divergence exists only for one exact fixture and disappears under modest state changes, flag `FRAGILE_DIVERGENCE`.
