# P0 Contextual Decision Reference Matrix

이 문서는 `docs/parallel/tasks/P0_CONTEXTUAL_DECISIONS_V1.md`의 행 단위 근거 장부다. F04C-R의 역사 사례는 `R01`–`R22`로 표기하고, 각 사례에서 추출한 좁은 메커니즘만 현재 TMR의 authoritative writer와 consumer에 연결한다. 생산 카탈로그의 비용·기간·delta는 역사 수치를 복사한 값이 아니라 현재 시나리오에 작성된 bounded content다.

공통 경로 표기:

- `P-W` = `src/sim/systems/policy.ts::runPolicyPhase`; `P-S` = `src/sim/state/policy.ts::evaluatePolicyAvailability`.
- `I-W` = `src/sim/systems/intervention.ts::runInterventionCompletionPhase`; `I-S` = `src/sim/systems/intervention.ts::runInterventionResolutionPhase`; `I-F` = `src/sim/state/intervention.ts::evaluateInterventionFeasibility`.
- `C-RULE` = `src/sim/systems/government.ts::deriveRegimeClassification` 및 `src/sim/systems/factionPressure.ts::deriveFactionObservation`의 실제 제도 규칙 소비.
- `C-AGENDA` = `src/sim/readModels/agenda.ts::derivePrimaryAgendas`; `C-SELECTOR` = `src/sim/readModels/contextualDecisions.ts::deriveContextualDecisionSurface`; `C-ROADMAP` = `src/app/institutionalRoadmap.ts::deriveInstitutionalRoadmap`.
- `C-RESOURCE` = `src/sim/systems/resources.ts::runResourcesPhase`; `C-PRESENTATION` = `src/app/stateProjects.ts::deriveStateProjectPresentations`.
- 정책의 `PA`는 `P-S`의 prerequisite·incompatibility·active 상태 평가와 selector의 실제 rule-change 필터를 뜻한다. 개입의 `IF`는 `I-F`의 terminal/country/treasury/admin-headroom/prerequisite/completion-effect-change 평가를 뜻한다.
